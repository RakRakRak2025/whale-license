## /festival — 장생포 시즌 에디션 (디지털 발급)

`festival/index.html` 한 파일로 동작합니다. 필기시험 3문제 → 등급 뽑기 → 면허증 이미지 발급(카드 / 인스타 스토리 9:16), 장생포 현장 도장, 매장 제시 화면.

배포 전에 파일 안의 `CONFIG` 블록만 채우면 됩니다.

| 항목 | 설명 |
|---|---|
| `EVENT.account` | 인스타 계정. 채우면 인증 이벤트 박스가 보임 |
| `EVENT.prize` / `EVENT.until` | 경품 · 마감일 문구 |
| `PARTNERS` | 혜택 매장 목록. 한 곳이라도 넣으면 '매장 제시' 버튼이 보임 |
| `SHOW_URL` | 스토리 이미지에 찍힐 주소 (비우면 현재 주소) |
| `GEO` | 현장 도장 기준 좌표·반경 |
| `GA_ID` / `GAS_URL` | (선택) 발급 수 집계 |

`og:image`는 배포 후 `https://<도메인>/festival/og.jpg` 절대주소로 바꿔야 카톡·인스타 링크 미리보기가 뜹니다.
