# 소셜마케팅연구소 랜딩페이지 기획안 (1차)

> 기준 자료: 회사 소개서 PDF 1~6쪽 (표지, 회사 소개, 연혁, 사업 영역, SNS·스튜디오). 7~20쪽은 아직 검토하지 않았습니다.

## 1. 목표

- 랜딩 페이지 **1장**(한 페이지 스크롤)으로 회사 신뢰도를 보여주고 **문의를 받는다.**
- 문의가 들어오면 **구글 시트에 저장 → 알림 메일이 대표 네이버 메일로 바로 도착**한다.

## 2. 회사 포지셔닝 (소개서 기준)

- 2014년 울산에서 가장 먼저 소셜 SNS를 시작한 **울산 대표 SNS 브랜드 에이전시**
- 사업 4축: **SNS 운영 · 스튜디오 · 공공기관/기업 · 브랜드**
- 지역 기반 (울산, 경주) 로컬 기업 신뢰가 핵심 차별점

## 3. 페이지 구조 (1P, 위에서 아래 순서)

| 순서 | 섹션 | 내용 | 소개서 출처 |
|---|---|---|---|
| 1 | 헤더 | 로고, 메뉴 3개(서비스 / 사례 / 문의), 문의 버튼 고정 | 로고 |
| 2 | 히어로 | "울산 대표 SNS 브랜드, 2014년부터" + 문의 버튼 | 쪽 2 |
| 3 | 신뢰 지표 | 2014년 시작 · 울산 SNS 운영 이력 · 공공기관 운영 | 쪽 3 |
| 4 | 서비스 4종 | SNS 운영 / 스튜디오 / 공공기관·기업 / 브랜드 | 쪽 5 |
| 5 | 대표 사례 | 테이스티울산, 테이스티부산, 유키즈울산, 울산오빠, 경주토끼 | 쪽 6 |
| 6 | 스튜디오 | 삼산동 푸드스튜디오 사진, 공간대여·행사·강연·CF촬영 | 쪽 7 |
| 7 | 진행 방식 | 상담 → 기획 → 운영 → 성과 공유 (3~4단계) | 신규 제안 |
| 8 | 문의 폼 | 아래 4번 항목 | 신규 |
| 9 | 푸터 | 연락처, 주소, 사업자 정보, 개인정보처리방침 링크 | 신규 |

## 4. 문의 폼 항목

필수
- 회사명 / 브랜드명
- 담당자 이름
- 연락처 (휴대폰)
- 이메일
- 문의 유형 (SNS 운영 / 스튜디오 대관·촬영 / 공공기관·기업 / 브랜드 / 기타)
- 문의 내용
- 개인정보 수집·이용 동의 (체크)

선택
- 희망 시기
- 월 예산 범위
- 참고 링크 (인스타그램, 유튜브 등)

## 5. 문의 → 알림 흐름

```
방문자 문의 제출
   → 구글 폼(또는 페이지 폼) → 구글 시트에 자동 저장
   → Apps Script 트리거(On form submit) 실행
   → 대표 네이버 메일 주소로 알림 메일 발송 (문의 내용 전체 포함)
   → (선택) 문의자에게 "접수 확인" 자동 회신
```

구현 방법 (2안)

| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| A (추천, 빠름) | 구글 폼 생성 → 응답 시트 → Apps Script로 네이버 메일 발송 | 코딩 최소, 바로 가능 | 페이지 디자인 안의 폼이 구글 폼 디자인 |
| B (디자인 우선) | 페이지 폼 → Apps Script 웹앱 URL로 전송 → 시트 저장 + 메일 발송 | 페이지 안에서 디자인 자유 | 스크립트 배포와 CORS 처리 필요 |

Apps Script 발송 방식 메모
- "구글 메일 → 네이버 메일 전달"은 Gmail 필터 전달로도 가능하지만, Gmail 전달 주소 인증 등 설정이 번거롭습니다. **Apps Script에서 네이버 주소로 직접 발송하는 쪽을 추천**합니다.
- Google 공식 샘플(폼 응답 기반 Gmail 발송 예제)을 기준으로 구현합니다. 워크스페이스 계정이면 관리자 승인이 필요할 수 있습니다.
- 네이버 메일이 알림을 스팸으로 분류할 수 있으니 첫 테스트 때 확인이 필요합니다.

## 6. 사이트 호스팅과 SEO

- Netlify 정적 배포 (`social-marketing-lab` 폴더, 1차 파일 이미 준비됨)
- SEO 파일: `index.html`의 title·meta·구조화 데이터, `robots.txt`, `sitemap.xml`
- 네이버 서치어드바이저 / 구글 서치 콘솔 등록은 배포 후 진행

## 7. 콘텐츠 확인이 필요한 항목 (발행 전 필수)

소개서에 있는 수치는 **근거 확인 후 사용**해야 합니다.

- "울산광역시 60~70% SNS 콘텐츠 독점" → 근거 자료 필요. 표시·광고 관련 위험이 있어 확인 전에는 쓰지 않는 것을 추천합니다.
- "매월 250~300만명 노출" → 측정 기준 (기간, 채널) 확인 필요
- 사례 로고 (테이스티울산 등) → 해당 브랜드 사용 허가 확인 필요

## 8. 레퍼런스 (이번 조사에서 확인 가능한 범위)

- 공식 샘플: 폼 응답 시 Gmail 발송 — Google Apps Script "Respond to feedback" 예제 (developers.google.com/apps-script/samples/automations/course-feedback-response)
- 공식 부가기능 예제: Google Forms 알림 메일 — developers.google.com/gsuite/add-ons/forms/quickstart/forms-notifications
- 대행사 선정 기준 칼럼 (성과를 투명하게 보여주는지 확인) — i-boss.co.kr 칼럼
- **한계**: 국내 SNS 대행사 랜딩페이지의 구체적 폼 구성 사례는 이번 검색에서 충분히 찾지 못했습니다. 실제 사이트 몇 곳을 직접 보고 덧붙이는 것을 추천합니다.

## 9. 결정이 필요한 항목

1. 문의 알림을 받을 **네이버 메일 주소**
2. 폼 방식: **A(구글 폼) / B(페이지 폼)** 중 선택
3. 최신 소개서 여부 (지금 것은 예전 버전이라고 하셨으니, 수정본이 있으면 공유 부탁드립니다)
4. 실제 연락처, 주소, 운영시간, 사업자 정보
5. 대표 사례 로고 사용 가능 여부
6. 1차 목표 문의 수 (예: 월 몇 건)

## 10. 다음 단계 (작업 순서)

1. 위 결정 항목 확정
2. 구글 폼 + 시트 + Apps Script 알림 설정 및 테스트 제출
3. 랜딩 페이지 본문 작성 (1P) → `index.html` 교체
4. 폼 연결 (A안이면 임베드 또는 링크 버튼)
5. Netlify 배포 → 네이버 서치어드바이저 등록 → 사이트맵 제출
