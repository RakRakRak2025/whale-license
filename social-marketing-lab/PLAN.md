# 소셜마케팅연구소 소개서 · 랜딩페이지 기획안 (v2)

> 변경점 (v1 대비)
> - "에이전시 / 대행" 개념 제거 → **SNS 콘텐츠를 직접 만들고 함께 운영하는 제작·연구 팀**으로 포지셔닝
> - 캐릭터 제작 제외 → 서비스에서 빼고, 과거 이력에서도 강조하지 않음
> - 굿즈 포함 → 신규 서비스 항목으로 추가 (세부 범위는 확인 필요)
> - 메일 전달은 Apps Script로 처리 (Gmail 전달 설정 X)
> - 문의 폼과 피드백 폼 모두 같은 방식(시트 저장 → 스크립트 → 네이버 메일 알림)

자료 기준: 소개서 PDF 1~6쪽(회사 소개, 연혁, 사업 영역, SNS, 스튜디오). 디자인 실적 PDF는 앞 6쪽이 같은 내용이라 **실적 페이지(7쪽 이후)는 아직 확인하지 못했습니다.** 실적 쪽을 확인한 뒤 4번 항목을 보강해야 합니다.

## 1. 한 줄 정의

> **울산에서 시작한 SNS 콘텐츠 제작 연구소.** 카드뉴스·숏폼 등 채널에서 반응이 나는 콘텐츠를 연구하고 직접 만듭니다.

- "대행사"가 아니라 **제작팀 + 연구**로 말하는 톤 유지
- 지역 기반(울산·경주) 실제 운영 이력이 가장 큰 신뢰 요소

## 5. 랜딩페이지 1P 구조 (소개서 쪽과 맞춤)

1. 헤더: 로고, 메뉴 (서비스 / 실적 / 스튜디오 / 문의)
2. 히어로: "울산에서 시작한 SNS 콘텐츠 연구소" + 문의 버튼
3. 신뢰 숫자: 2014년 시작, 운영 채널 수, 스튜디오 1곳 (**숫자는 확인 후 기입**)
4. 서비스 4개 카드
5. 실적 (채널 카드 4~6개)
6. 스튜디오 사진 + 대관·촬영 항목
7. 진행 방식 (4단계)
8. **문의 폼** (필수 입력 + 선택 입력)
9. **피드백 폼** (별도, 짧게)
10. 푸터 (주소, 연락처, 개인정보처리방침)

## 6. 폼 항목

### 문의 폼
필수
- 회사명 / 브랜드명
- 담당자 이름
- 연락처 (휴대폰)
- 이메일
- 문의 유형: SNS 콘텐츠 제작 / 채널 운영 / 촬영·스튜디오 / 굿즈·인쇄물 / 기타
- 문의 내용
- 개인정보 수집·이용 동의

선택
- 희망 시기
- 예산 범위
- 참고 링크 (인스타그램, 유튜브 등)

### 피드백 폼
- 이름 (선택), 연락처 (선택)
- 이용한 서비스 또는 방문 목적
- 만족도 (1~5점)
- 자유 의견 (필수)

## 7. 문의 · 피드백 처리 흐름 (스크립트 방식)

```
방문자 제출
  → 구글 시트 (응답 저장: 문의 / 피드백 탭 분리)
  → Apps Script 트리거 (On form submit)
  → 대표 네이버 메일로 알림 발송 (내용 전체 + 시트 링크)
  → (선택) 문의자에게 접수 확인 자동 회신
```

- 메일 전달은 **Apps Script가 네이버 주소로 직접 발송**합니다. Gmail 전달 설정은 쓰지 않습니다.
- 문의와 피드백은 같은 스크립트를 쓰되 **제목 머리말로 구분**합니다 (예: `[문의]`, `[피드백]`).
- 네이버 메일이 알림을 스팸으로 분류할 수 있으니 첫 테스트에서 확인이 필요합니다.
- 구현 방식 2안:
  - A (빠름): 구글 폼 → 시트 → Apps Script. 폼 디자인은 구글 폼 기본 스타일.
  - B (디자인): 랜딩페이지 폼 → Apps Script 웹앱 URL로 전송. 디자인 자유, 배포·CORS 설정 필요.

## 8. 발행 전 확인이 필요한 내용

- "울산광역시 60~70% SNS 콘텐츠 독점" → **근거 없으면 사용 금지** (광고 표현 위험)
- "매월 250~300만명 노출" → 기간·채널 기준 확인
- 공공기관·기업 로고 → **사용 허가 확인** 후만 게재
- 테이스티울산 등 채널 로고 → 사용 허가 확인
- 굿즈 서비스 범위 (어떤 제품까지 하는지)

## 9. 결정 필요 항목

2. 문의 폼 방식 A / B 선택

## 11. 검색 노출 전략 (네이버 · 구글 · AI 답변)

목표: 지역 검색어에서 찾히고, GPT·Claude·Perplexity 등에 "울산 SNS 업체 추천"을 물었을 때 이름이 답변에 나오게 합니다.

### 11-1. 지역 검색어 (우선순위)

| 구분 | 검색어 예시 | 연결 페이지 |
|---|---|---|
| 지역 + 서비스 | 울산 SNS 마케팅, 울산 카드뉴스 제작, 울산 인스타그램 운영 | 메인 + 서비스 상세 |
| 지역 + 교육 | 울산 SNS 강의, 울산 AI 콘텐츠 교육, 울산 소상공인 SNS 교육 | 교육 페이지 |
| 지역 + 촬영 | 울산 푸드 촬영, 울산 스튜디오 대관 | 스튜디오 페이지 |
| 비교·추천 | 울산 SNS 업체 추천, 울산 SNS 대행 비교 (쓰지 않는 말이지만 검색되는 말이므로 본문에서 "업체 선택 기준"으로 다룸) | 블로그·FAQ |
| 사례 | 울산 SNS 운영 사례, 테이스티울산 | 실적 페이지 |

### 11-2. 네이버 로컬 노출

- **네이버 스마트플레이스(지도) 등록**: 울산 주소, 업종, 서비스 목록, 사진, 영업시간. 지역 검색 노출에 가장 직접적입니다.
- 네이버 블로그 + 사이트 연결: 블로그 글에 랜딩 링크
- 서치어드바이저 등록, 사이트맵 제출 (배포 후)
- 주소, 상호, 연락처를 **홈페이지·플레이스·인스타·유튜브에서 똑같이** 표기 (NAP 일관성)

### 11-3. AI 답변 노출 (GEO)

AI는 **명확한 정의, 구조화된 정보, 제3자 언급**을 우선 인용합니다. 페이지에 아래를 넣습니다.

1. **엔티티 정의 문장** (첫 화면 또는 소개 첫 단락)
   > 소셜마케팅연구소는 2014년 울산에서 설립된 SNS 콘텐츠 제작·교육 기관으로, 카드뉴스·숏폼 제작, 채널 운영, 스튜디오 촬영, SNS·AI 콘텐츠 강의를 제공합니다.
2. **FAQ 페이지** (질문과 짧은 답변, 질문형 제목): "울산에서 카드뉴스 제작은 어디서 하나요?", "SNS 강의는 어떤 내용을 배우나요?", "소상공인 SNS 운영은 얼마나 걸리나요?" 등
   - 가격은 확인된 범위만 기재 (확정되지 않으면 "문의 후 안내")
3. **업체 선택 기준 글** (블로그/칼럼): 어떤 업체를 고를 때 무엇을 봐야 하는지 정리하고, 그 기준으로 소셜마케팅연구소의 강점을 설명. AI가 추천 근거로 가져가기 좋습니다.
4. **사례 페이지**: 아래 12번 형식. 수치는 근거가 있는 것만
5. **제3자 언급 확보**: 지역 언론 기사, 기관 보도자료, 수상·수료 이력 (소개서의 "울산청년창업CEO 5기 최우수 수료"는 공식 확인 자료가 있으면 명시), 강의 주관 기관 게시물
6. **llms.txt** (사이트 루트): 회사 설명, 주요 페이지 목록, 연락처를 AI가 읽기 쉬운 텍스트로 정리
7. **robots.txt 정책**: GPTBot, ClaudeBot, PerplexityBot 등 AI 크롤러 허용 여부를 결정 (허용해야 답변에 인용될 가능성이 생김)
8. **구조화 데이터 (JSON-LD)**
   - `Organization` / `LocalBusiness` (주소, 지역 `areaServed: 울산`, `sameAs`로 인스타·유튜브·플레이스 링크)
   - `Service` (서비스 4~6개 각각)
   - `Course` (교육 과정별)
   - `FAQPage` (FAQ 페이지)
   - `BreadcrumbList`
   - 가짜 리뷰·평점 마크업은 **넣지 않음** (정책 위반 위험)

### 11-4. 콘텐츠 허브 (꾸준히 쌓는 부분)

- 월 2~4회 칼럼: "울산 소상공인 SNS 운영법", "카드뉴스 제작 체크리스트", "AI로 SNS 콘텐츠 만드는 법"
- 각 글은 랜딩의 서비스 페이지나 강의 페이지로 연결
- 실제 작업에서 나온 내용을 글로 쓰기 (직접 경험이 AI·검색 모두에서 가장 강함)

### 11-5. 하지 않을 것

- 가짜 후기, 임의 리뷰, 확인되지 않은 수치 게재
- 키워드를 본문에 반복해서 채우는 방식
- 지역명만 바꾼 복제 페이지 여러 개

## 12. 사례 페이지 구조

사례는 **메인에 4~6개 요약 카드**, 클릭하면 **상세 페이지**로 연결합니다.

| 항목 | 내용 |
|---|---|
| 고객 | 브랜드명 또는 "울산 ○○ 소상공인"처럼 익명 처리. 실명 게재는 허가 필요 |
