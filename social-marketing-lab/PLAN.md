# 소셜마케팅연구소 소개서 · 랜딩페이지 기획안 (v2)

> 변경점 (v1 대비)
> - "에이전시 / 대행" 개념 제거 → **SNS 콘텐츠를 직접 만들고 함께 운영하는 제작·연구 팀**으로 포지셔닝
> - 캐릭터 제작 제외 → 서비스에서 빼고, 과거 이력에서도 강조하지 않음
> - 굿즈 포함 → 신규 서비스 항목으로 추가 (세부 범위는 확인 필요)
> - 메일 전달은 Apps Script로 처리 (Gmail 전달 설정 X)
> - 문의 폼과 피드백 폼 모두 같은 방식(시트 저장 → 스크립트 → 네이버 메일 알림)

자료 기준: 소개서 PDF 1~6쪽(회사 소개, 연혁, 사업 영역, SNS, 스튜디오). 디자인 실적 PDF는 앞 6쪽이 같은 내용이라 **실적 페이지(7쪽 이후)는 아직 확인하지 못했습니다.** 실적 쪽을 확인한 뒤 4번 항목을 보강해야 합니다.

## 1. 한 줄 정의

> **울산에서 시작한 SNS 콘텐츠 제작 연구소.** 카드뉴스·숏폼 등 채널에서 반응이 나는 콘텐츠를 연구하고 직접 만듭니다.

- "대행사"가 아니라 **제작팀 + 연구**로 말하는 톤 유지
- 지역 기반(울산·경주) 실제 운영 이력이 가장 큰 신뢰 요소

## 5. 랜딩페이지 1P 구조 (소개서 쪽과 맞춤)

1. 헤더: 로고, 메뉴 (서비스 / 실적 / 스튜디오 / 문의)
2. 히어로: "울산에서 시작한 SNS 콘텐츠 연구소" + 문의 버튼
3. 신뢰 숫자: 2014년 시작, 운영 채널 수, 스튜디오 1곳 (**숫자는 확인 후 기입**)
4. 서비스 4개 카드
5. 실적 (채널 카드 4~6개)
6. 스튜디오 사진 + 대관·촬영 항목
7. 진행 방식 (4단계)
8. **문의 폼** (필수 입력 + 선택 입력)
9. **피드백 폼** (별도, 짧게)
10. 푸터 (주소, 연락처, 개인정보처리방침)

## 6. 폼 항목

### 문의 폼
필수
- 회사명 / 브랜드명
- 담당자 이름
- 연락처 (휴대폰)
- 이메일
- 문의 유형: SNS 콘텐츠 제작 / 채널 운영 / 촬영·스튜디오 / 굿즈·인쇄물 / 기타
- 문의 내용
- 개인정보 수집·이용 동의

선택
- 희망 시기
- 예산 범위
- 참고 링크 (인스타그램, 유튜브 등)

### 피드백 폼
- 이름 (선택), 연락처 (선택)
- 이용한 서비스 또는 방문 목적
- 만족도 (1~5점)
- 자유 의견 (필수)

## 7. 문의 · 피드백 처리 흐름 (스크립트 방식)

```
방문자 제출
  → 구글 시트 (응답 저장: 문의 / 피드백 탭 분리)
  → Apps Script 트리거 (On form submit)
  → 대표 네이버 메일로 알림 발송 (내용 전체 + 시트 링크)
  → (선택) 문의자에게 접수 확인 자동 회신
```

- 메일 전달은 **Apps Script가 네이버 주소로 직접 발송**합니다. Gmail 전달 설정은 쓰지 않습니다.
- 문의와 피드백은 같은 스크립트를 쓰되 **제목 머리말로 구분**합니다 (예: `[문의]`, `[피드백]`).
- 네이버 메일이 알림을 스팸으로 분류할 수 있으니 첫 테스트에서 확인이 필요합니다.
- 구현 방식 2안:
  - A (빠름): 구글 폼 → 시트 → Apps Script. 폼 디자인은 구글 폼 기본 스타일.
  - B (디자인): 랜딩페이지 폼 → Apps Script 웹앱 URL로 전송. 디자인 자유, 배포·CORS 설정 필요.

## 8. 발행 전 확인이 필요한 내용

- "울산광역시 60~70% SNS 콘텐츠 독점" → **근거 없으면 사용 금지** (광고 표현 위험)
- "매월 250~300만명 노출" → 기간·채널 기준 확인
- 공공기관·기업 로고 → **사용 허가 확인** 후만 게재
- 테이스티울산 등 채널 로고 → 사용 허가 확인
- 굿즈 서비스 범위 (어떤 제품까지 하는지)
